# ADR-0001 — Record architecture decisions

- **Status**: Accepted
- **Date**: (commit 0)

## Decision
Every structural choice (stack, dependency, layer, cross-module pattern, published interface) is an
ADR in this folder, in the short form of `template.md`. Smaller choices are recorded as `Decision:`
lines in commit bodies (skill `decide`).

## Options rejected
Decisions in chat or tickets only: invisible to the agent, which starts every session from the repository.

## Revisit if
Nobody reads them: then shorten, do not stop.
